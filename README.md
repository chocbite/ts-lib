# ts-lib

TypeScript libraries, published as two npm packages:

- `@chocbite/ts-lib`: platform independent, no browser features.
- `@chocbite/ts-lib-ui`: browser UI libraries built on ts-lib.

Modules are imported by subpath, e.g. `import st from "@chocbite/ts-lib/state"`. See `AGENTS.md` for layout and commands, and the `README.md` in each module folder.
